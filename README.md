# Sistema de Gerenciamento de Notas Escolares

Este projeto é uma aplicação de linha de comando desenvolvida em Python para auxiliar professores no cálculo de médias acadêmicas e na verificação automática do status de aprovação dos alunos.

## 🚀 O que o código (`script.py`) faz:

* **Entrada Dinâmica:** O usuário escolhe quantas notas quer digitar para o aluno.
* **Cálculo de Média:** O script soma todas as notas inseridas e faz a média aritmética exata.
* **Validação de Segurança:** O código não aceita textos ou notas menores que 0 e maiores que 10, evitando erros na execução.
* **Classificação do Aluno:** 
  * Se a média for **maior ou igual a 7.0**, exibe "Aprovado(a)".
  * Se a média estiver **entre 5.0 e 6.9**, exibe "Em Recuperação".
  * Se a média for **menor que 5.0**, exibe "Reprovado(a)".

## 🛠️ Tecnologias Utilizadas

* **Python 3** (Funções, listas, estruturas de repetição `for` e tratamento de erros com `try/except`).
* **Markdown** (Estruturação e organização deste arquivo de documentação).

## 📋 Como Executar e Testar o Script

1. Abra o terminal do seu computador dentro da pasta `atividade-python-pratica`.
2. Execute o comando abaixo para iniciar o programa:
   ```bash
   python script.py
   ```
3. Digite a quantidade de notas, insira os valores no terminal e veja o resultado do cálculo da média na tela.
